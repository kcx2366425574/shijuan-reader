一、P0：先修的 Bug（用户可感知，改动小）
====================================================================

[x] 1. 修复阅读器“重试本章”重试错误章节
    位置：src/pages/reader/reader.vue:449、497-502、613-615
    问题：currentIndex 在请求成功后才更新。从目录跳到第 300 章失败后，
          点“重试本章”实际会重新加载原来的章节（可能是第 1 章）。
    做法：新增 pendingIndex（或把 currentIndex 提前赋值），失败时记录目标章节，
          retryChapter 使用该目标索引重试。
    验收：跳到靠后章节 → 断网 → 加载失败 → 恢复网络点“重试本章” → 加载的是目标章节。

[x] 2. 修复书源页“清空搜索缓存”假按钮
    位置：src/pages/sources/sources.vue:466-479
    问题：菜单项只弹 toast，没有真正清缓存；mine.vue:474 才是正确实现。
    做法：引入并调用 clearHttpCache()、clearBookCache()。
    验收：点击后缓存被清空（可在下次搜索时观察重新请求）。

[x] 3. 修复目录“定位”只翻页不跳章
    位置：src/pages/reader/reader.vue:674-684
    问题：输入章节号后只切换目录分页并提示“已定位”，用户会误以为已在阅读。
    做法：定位后滚动目录列表到目标项；或提供“定位到列表 / 直接阅读”两种行为。
    验收：输入 300 → 目录跳到第 300 章所在页并高亮 → 可直接点击阅读。

[x] 4. 搜索结果增量展示
    位置：src/pages/discover/discover.vue:351-400
    问题：groups 只在全部书源完成后赋值，快源结果被最慢的索引源拖住
          （yoboi 首次搜索可能几十秒）。
    做法：在 onSourceDone 中合并已完成的结果并刷新 groups；
          增加“停止等待/先看已有结果”能力。
    验收：慢源未完成时，快源结果已可出现；完成状态与最终结果一致。

[x] 5. 加载中重复点击章节的反馈
    位置：src/pages/reader/reader.vue:454
    问题：loadingChapter 为 true 时，再点“下一章”直接 return，无任何反馈。
    做法：忽略重复请求但给出轻提示，或排队最后一次目标章节。
    验收：连续快速点击下一章，不会误以为卡死，也不会并发请求。

二、P1：稳定性与性能
====================================================================

[ ] 6. 请求层增加重试与取消
    位置：src/core/service.js:105-188
    做法：GET 请求对超时/5xx 做 2 次指数退避重试；429 单独退避；
          阅读页离开、搜索词切换时取消在途请求（AbortController / uni.request abort）。
    验收：弱网下正文加载成功率提升；切页后旧请求不再回写界面。

[ ] 7. 优化索引搜索的补详情延迟
    位置：src/core/service.js:393-431、542-544
    问题：首搜最多补 24 本详情，单页 12s、并发 4，最坏接近一分钟。
    做法：只补当前可见的前 6-8 本，其余后台增量回填；结果先返回再补全。
    验收：yoboi 首次搜索可感知耗时明显下降，封面/作者仍能渐进补齐。

[ ] 8. 书源仓库同步优化
    位置：src/core/source-repo.js:258-304、236-239、306
    做法：
      a) 并发 3-4 拉取书源文件；
      b) 用 index.json 条目的 version 跳过未变化项；
      c) manifest.engine 高于当前引擎时保留旧规则，不直接覆盖；
      d) 清单中移除的源标记为“已下架”，不静默残留。
    验收：同步耗时下降；引擎不兼容时不破坏现有可用书源。

[ ] 9. 缓存加上限
    位置：src/core/service.js:364（indexSearchCache）、200-224（responseCache）、
          src/components/BookCover.vue（coverCache）
    做法：统一按条目数或字节数做 LRU，暴露 clear 方法。
    验收：长时间使用后内存不持续增长。

[ ] 10. 目录与书籍信息持久化
    位置：src/core/book-cache.js
    问题：缓存仅在内存，App 重启后必须重新请求目录；书源失效时书架里的书打不开。
    做法：把书名、作者、封面、目录、tocUrl 持久化到本地存储（按 bookId），
          阅读页优先用本地目录，后台刷新。
    验收：飞行模式下可打开已读过的书并看到目录。

[ ] 11. 阅读进度单独存储 + 节流
    位置：src/pages/reader/reader.vue:413-427、src/core/store.js:290-299
    问题：滚动结束会把整张书架同步写入 storage。
    做法：进度独立 key，2 秒节流；书架数据只在增删改时写。
    验收：滚动时无卡顿；进度恢复正常。

[ ] 12. 增加 CI
    位置：仓库根目录 .github/workflows/
    做法：push 时运行 npm ci + npm test + npm run build:h5；
          书源仓库增加定时联网巡检（见第四节）。
    验收：PR/推送自动跑测试。

[ ] 13. 增加全局错误处理与诊断信息
    位置：src/main.js、src/App.vue、“我的”页
    做法：Vue errorHandler + 本地诊断日志；提供“复制诊断信息”
          （版本、书源、URL、阶段、错误、时间）。
    验收：可一键得到可用于反馈的文本。
